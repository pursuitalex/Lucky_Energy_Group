# Lucky Energy

Сайт та інтернет-магазин систем енергонезалежності: інвертори, акумулятори, сонячні панелі, генератори.

Статичний сайт на HTML, CSS і JavaScript (ES-модулі) без фреймворків і залежностей. Дані в `web/data/*.json` демонстраційні.

## Структура

- `web/` — готовий сайт, його й публікуємо.
- `tools/pages/*.main.html` — вміст внутрішніх сторінок.
- `tools/build-*.cjs` — збирачі: додають до вмісту спільні шапку, футер та іконки з `web/index.html`.

## Локальний запуск

```bash
node tools/serve.mjs
```

Сайт відкривається на http://localhost:4173.

## Збірка сторінок

Після змін у `web/index.html`, `tools/pages/*` або збирачах:

```bash
node tools/build-all.cjs
```

Зібрані HTML-файли зберігаються в репозиторії, тому хостингу збірка не потрібна.

## Публікація

Vercel публікує вміст папки `web/`, налаштування в `vercel.json`. Сайт закритий від індексації трьома способами: заголовок `X-Robots-Tag` на всі відповіді, `<meta name="robots">` на кожній сторінці та `web/robots.txt`.
