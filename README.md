# Lucky Energy

Сайт та інтернет-магазин систем енергонезалежності: інвертори, акумулятори, сонячні панелі, генератори.

Статичний сайт на HTML, CSS і JavaScript (ES-модулі) без фреймворків і залежностей. Дані в `site/data/*.json` демонстраційні.

## Структура

- `site/` — готовий сайт: сторінки, стилі, скрипти, зображення й дані. Саме цю папку публікує хостинг.
- `vercel.json` — налаштування публікації на Vercel.

## Локальний перегляд

Підійде будь-який статичний сервер, запущений у папці `site/`, наприклад:

```bash
npx http-server site -p 4174 -c-1
```

Сайт відкривається на http://localhost:4174.

## Публікація

Vercel публікує вміст папки `site/` без збірки. Сайт закритий від індексації трьома способами: заголовок `X-Robots-Tag` на всі відповіді, `<meta name="robots">` на кожній сторінці та `site/robots.txt`.
